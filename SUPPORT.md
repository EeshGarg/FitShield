# Getting help

## Using FitShield

Start with [CONSUMERS.md](CONSUMERS.md): installation, how blocking and passes
work, and the FAQ. Most questions are answered there.

## Something is broken

Open an issue using the templates:

- **Bug report** for a defect in the extension or Android app. For the extension, open the diagnostics page and paste what it shows (runtime, blocklist and rules, last decision, last error).
- **Data correction** for a wrong or missing brand, domain or Android package.
- **Store policy or publication blocker** for a store rejection.

Security vulnerabilities must not be filed as issues. See [SECURITY.md](SECURITY.md).

## Maintenance mode

FitShield 1.0 is the final feature release. The project accepts only:

- critical defects
- security issues
- compatibility updates (browser or Android changes)
- publication blockers
- data corrections

Feature requests are not being accepted and will be closed. Response times are
best-effort; this is not a commercial support channel.

To contribute a fix, read [CONTRIBUTING.md](CONTRIBUTING.md) and use the pull
request template.
